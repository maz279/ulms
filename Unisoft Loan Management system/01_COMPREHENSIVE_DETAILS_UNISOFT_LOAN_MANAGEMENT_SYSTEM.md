## HOW BANKS NORMALLY MANAGE LOAN PROCESSES

### Traditional Loan Management Workflow

#### Stage 1: Customer Requisition (Branch Level)
```
Customer Visit → Loan Inquiry → Basic Information Collection
                                    ↓
                    Physical Document Submission
                                    ↓
                    Forward to Branch Credit Committee
```

**Typical Duration:** 1-2 days
**Pain Points:**
- Physical presence required
- Incomplete documentation
- Data re-entry errors
- No preliminary screening

#### Stage 2: Branch Officers Credit Committee (BOCC) Review
```
Application Intake → Committee Meeting → Discussion & deliberation
                                          ↓
                            Manual Recommendation Preparation
                                          ↓
                              Branch Manager Approval
```

**Typical Duration:** 2-3 days
**Pain Points:**
- Meeting scheduling delays
- Manual minute preparation
- Paper-based documentation
- Limited data analysis

#### Stage 3: Credit Analysis & Processing
```
Data Entry → CIB Manual Inquiry → Reference Check → CPV Assignment
                                                   ↓
                                        Credit Analysis & DBR Calculation
                                                   ↓
                                              Credit Memo Preparation
```

**Typical Duration:** 3-5 days
**Pain Points:**
- Manual CIB inquiry (30-60 minutes per application)
- Time-consuming verification processes
- Spreadsheet-based calculations
- Delayed coordination

#### Stage 4: Head Office Approval
```
HO Credit Review → Distribution to Analysts → Detailed Assessment
                                              ↓
                              Recommendation Preparation
                                              ↓
                                  Multi-Level Approval
```

**Typical Duration:** 2-4 days
**Pain Points:**
- Physical file movement between departments
- Serial processing delays
- Communication gaps
- Lack of real-time status visibility

#### Stage 5: Disbursement
```
Documentation Verification → Security Creation → Legal Opinion
                                                ↓
                                    CBS Limit Loading
                                                ↓
                                          Disbursement
```

**Typical Duration:** 2-3 days
**Pain Points:**
- Incomplete documentation causes delays
- Manual verification processes
- CBS integration challenges

#### Stage 6: Servicing & Collection
```
EMI Monitoring → Payment Collection → Overdue Tracking → Follow-up Actions
```

**Ongoing Challenges:**
- Manual DPD calculation
- Delayed NPA identification
- Inconsistent collection processes
- Reactive rather than proactive management

### Current Challenges Summary

| Challenge | Impact | Frequency |
|-----------|--------|-----------|
| Manual Processing | 7-15 day turnaround | All loans |
| Data Entry Errors | 5-10% error rate | High |
| CIB Verification Delays | 30-60 minutes | Every loan |
| Limited Customer Visibility | No status tracking | Always |
| Reactive NPA Management | Delayed identification | Monthly |
| Regulatory Compliance Burden | Manual report preparation | Monthly/Quarterly |
| Branch-HO Communication Delays | File movement time | Every loan |
