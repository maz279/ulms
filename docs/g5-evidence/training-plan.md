# Training Plan — ULMS Go-Live (R9, guide 8.6/8.7)

Four tracks, delivered in the 2 weeks before go-live; recordings + quick refs
become the onboarding pack. Attendance recorded (G5 item 9).

| Track | Audience | Size | Duration | Materials |
|-------|----------|------|----------|-----------|
| Branch officers | Loan officers + tellers | ~400 | 2×2h hands-on | quick-ref card (wizard, CPV, payments), recording |
| Approvers | Branch managers, regional, HO credit, committee | ~50 | 3h | ladder + BOCC + sanction letters walkthrough |
| Compliance | BFIU/reporting team | ~15 | 3h | EOD board, CL pack, regcon calendar, STR filing |
| Ops + support | IT ops, helpdesk | ~12 | 4h | runbooks RB-01..11, monitoring dashboards, rollback drill |

## Quick-reference topics per role (one page each)
- Branch officer: start application → verify KYC → upload docs → track status → post payment
- Approver: my-inbox → review one-pager → approve/return/reject → BOCC sitting → close with minutes
- Collections: today's list → call/visit logging → PTP → broken-promise follow-up → field task from mobile
- Compliance: nightly EOD check → 7-class board → CL generate/check/file → submission calendar watch
