```
┌─────────────────────────────────────────────────────┐
│         TROUBLESHOOTING QRG                         │
├─────────────────────────────────────────────────────┤
│  CAN'T LOGIN?                                       │
│  • Check Caps Lock                                  │
│  • Try resetting password                           │
│  • Clear browser cache (Ctrl+F5)                   │
│  • Try different browser                            │
├─────────────────────────────────────────────────────┤
│  PAGE NOT LOADING?                                  │
```
